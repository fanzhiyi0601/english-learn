# Design

## Context

承接第 1 轮已归档的静态展示 + 选择题练习 + 金币奖励系统（见 openspec/changes/archive/2026-10-20-kids-english-learning）。本轮在同一套纯前端架构上迭代，技术约束不变：零第三方运行时依赖、浏览器 TTS、localStorage 持久化、Vitest 单元测试。动机见 proposal - Why。

## Goals / Non-Goals

**Goals:**
- 卡片居中放大预览（点外部关闭）
- 首页动画模块：配置驱动播放英文动画，预留后端接入点
- 听写题型与选择题并列随机出现；支持物理键盘 + 屏幕虚拟软键盘
- 错题本：记录失败作答，顶部导航入口，localStorage 持久化
- 修复金币徽标图标方框问题

**Non-Goals:**
- 不做错题本"改错重做"、不做学习进度报告
- 不引入后端/数据库（仍用本地存储）
- 动画内容 v2 阶段仅内置一条配置项，不批量做内容库

## Decisions

### 决策 1：卡片预览用全屏遮罩 + 居中卡片

- **选择**：点击卡片时在页面叠加一个半透明全屏遮罩层，中央显示放大的卡片副本（含大号内容）；点击遮罩（外部区域）即移除遮罩与预览。
- **理由**：对幼儿最直观，遮罩隔离误触，点外部任意处即关闭。放大内容直接用原卡片数据重新渲染，保证一致。
- **备选**：就地 scale 放大——易超出视口、误触边界难处理。弃用。

### 决策 2：动画模块配置驱动，内置单条播放项

- **选择**：定义 `ANIMATIONS` 配置数组（`{ id, title, src }`），播放器从配置渲染列表并 `<video>` 播放。当前内置一条短英文动画，`src` 指向 `assets/english-demo.mp4`；未来接数据库时仅替换配置数据的来源（如 fetch 接口返回同构数组），播放逻辑不变。
- **理由**：满足"先固定一个较短动画 + 之后接数据库"的演进需求，结构解耦。
- **资源现实约束**：当前沙箱无网络、也无自带视频文件，故 `assets/english-demo.mp4` 为占位路径；实现时若文件缺失则优雅显示"暂无可播放动画"占位提示并预留替换点，用户放入真实视频文件即可生效。不影响其余功能交付。

### 决策 3：听写题型与选择题并列随机

- **选择**：练习生成器以合理的概率在【选择题】与【听写题】之间随机选题型；听写题播放目标音频（TTS），孩子输入听后内容。`practice-quiz` 的题型分发逻辑抽为纯函数，便于测试。
- **理由**：题型#并列出现"符合需求；随机混出避免单一枯燥。
- **判定**：字母题要求输入 1 个字母且与答案忽略大小写匹配；单词/句子题按词比较（忽略大小写与首尾空格），全对才判对。

### 决策 4：听写输入 = 物理键盘 + 虚拟软键盘

- **选择**：听写输入框支持直接键入；同时提供一个屏幕虚拟字母键盘（26 字母 + 空格 + 退格 + 提交），点击对应键即输入。虚拟键盘在听写题出现时显示。
- **理由**：触屏/低龄用户无物理键盘可用，虚拟键盘保证可操作；同时兼容电脑键盘。
- **实现**：虚拟键盘的输入写入同一个输入模型，与物理键盘共用判定逻辑。

### 决策 5：错题本本地存储

- **选择**：`src/mistakes.js` 提供 `recordMistake`、`getMistakes`、`clearMistakes`（可选）纯函数，基于 localStorage（key=`mistakeBook`）存储 `[{ module, prompt, answer, userAnswer, ts }]`；答错时写入。
- **理由**：沿袭 coins 的 localStorage 模式，无后端；错题本仅存储与展示。
- **入口**：顶部导航栏新增"错题本"按钮，切换至错题本视图渲染列表。

### 决策 6：金币图标修复

- **选择**：金币徽标前的 `🪙`(U+1FA99) 替换为广泛支持的 `💰` 或 `⭐`，并作为可渲染符号。根因是系统字体不支持该 emoji，非转义或渲染逻辑问题。
- **理由**：`💰`(U+1F4B0) 在 Windows/主流浏览器广泛支持，避免方框。

## Risks / Trade-offs

- [动画占位视频缺失] → 播放器检测 `src` 不可加载时显示占位提示，不中断其他功能；用户放入真实视频即生效。
- [虚拟键盘布局对幼儿可能不够直观] → 按字母序排列大按钮，与字母卡一致。
- [听写判定过于严格打击趣味] → 忽略大小写与首尾空格；单词/句子按词级比较，避免因单个空格被判错。
- [错题本 localStorage 可能被清空] → 读取失败时回退为空列表。
